# 백그라운드·Ubuntu 서버1.3

## Android 기기
연구실에서 ‘현재 모의세션 백그라운드로 전환’을 누르면 같은 모의계좌/EMA 준비 상태를 서비스로 넘깁니다. ‘백그라운드·Ubuntu 서버’ 화면에서는 별도의 새 기기 모의세션을 시작할 수도 있습니다. 기기 서비스는 선택 종목의 업비트 KRW 모의매매용이며 기존 전체 마켓/김프 화면의 백그라운드 상시 갱신을 뜻하지 않습니다.

중지 버튼이 있는 지속 알림을 사용합니다. Android13+에서 알림 권한이 없으면 OS 작업 관리자에만 표시될 수 있습니다. 서비스는 화면 꺼짐 관찰을 위해 제한시간이 있는 partial wake lock을 사용하므로 배터리를 소비합니다. 절전 제외 설정을 자동 변경하지 않습니다.

세션은 자체 최대5시간45분, Android15의 dataSync 서비스 시간 총량/OS 종료에 의해 더 일찍 정지될 수 있습니다. onTimeout에서 연결·잠금을 해제하고 잔여 모의 보유분을 유지한 채 중지합니다. 부팅 자동 실행/시간 제한 우회는 없습니다. 앱을 강제 종료하거나 OS가 프로세스를 죽이면 중단됩니다. 마지막 리포트는 기기 내부 파일에 보존하며 자동 재개하지 않습니다. 24시간 독립 실행은 서버를 사용하세요.

공식 제한: https://developer.android.com/develop/background-work/services/fgs/timeout

## iPhone / Ubuntu 서버
연구실 → ‘백그라운드·Ubuntu 서버’에서 HTTPS 주소와 서버 토큰을 저장하고 상태를 확인합니다. 서버 세션은 휴대폰 연결·앱 종료와 독립적으로 유지됩니다. 앱의 상태 갱신은 화면 활성 시 약10초 간격이며, 주소/토큰 초안은 자동 전송하지 않습니다. 새 서버 세션 시작·정지는 CONTROL_TOKEN, 읽기는 VIEW_TOKEN으로 구분합니다. 거래소 API 키가 아닙니다.

iOS 로컬 모의전략은 기존처럼 백그라운드에서 정지하며 음성/위치 등 우회 모드는 사용하지 않습니다. OS가 임의 시점에 실행하는 BGAppRefresh를 상시 전략 실행으로 표현하지 않습니다.

공식 백그라운드 정책: https://developer.apple.com/documentation/backgroundtasks/choosing-background-strategies-for-your-app

Ubuntu LTS/Gram 설치 파일은 background_server/입니다. Docker Compose와 Caddy HTTPS, 로컬 SQLite 저장소, 단일 프로세스 모의 엔진을 제공합니다. 실제 서버 주소는 추측해 넣지 않았고 서버 배포도 실행하지 않았습니다. 설치 후 사용자가 주소/토큰을 앱에 입력합니다. 절전/전원 중단 및 시세15초 공백·서버 재시작에서는 계좌를 보존하고 정지합니다. 상세 절차와 복구는 background_server/README_KO.md를 따르세요.

## 검증 범위
서버/모바일 테스트는 가짜 시세·가짜 응답으로 수명주기, 상태 보존, 권한, 입력·URL 제한, 비용 결과를 확인합니다. 실제 Ubuntu 서버 설치, TLS 외부 접속, 휴대폰 화면 꺼짐·제조사 절전 정책, 장시간 운영, 실계좌 연동은 별도 검증입니다. 모바일과 Ubuntu 서버는 모의매매 전용이며 operator/ 실거래 준비본과 연결하지 않습니다.
