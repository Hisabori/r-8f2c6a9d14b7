# 설치와 사용 안내

Android 8 이상: CryptoResearch-Android-1.1.0-debug.apk를 기기에 복사해 설치합니다. 개발용 서명 APK이며 스토어 배포용이 아닙니다.
iOS 16 이상: CryptoResearch-iOS-1.1.0-unsigned.ipa를 Sideloadly / AltStore / SideStore에서 본인 Apple 계정으로 재서명해 설치합니다. 무서명 IPA를 직접 탭해서 설치할 수 없습니다. 계정·인증서는 이 프로젝트에 넣지 마세요.

마켓에서 '실시간 시세 연결'을 눌러 시작합니다. 앱이 백그라운드로 가면 연결을 닫습니다. 연결 후의 관측값만 차트에 표시합니다. 과거 데이터를 만들거나 서버에 보관하지 않습니다.
관심 종목은 별 버튼으로 관리합니다. 설정에서 수동 환율과 FX 김프 알림 기준을 지정합니다. 자동 환율은 일별 기준이며 실패 시 수동값을 자동 적용하지 않습니다. 알림은 앱 내부 표시·기록 전용입니다.
업비트 KRW와 바이낸스 spot USDT를 비교합니다. FX 김프는 USDT=USD 가정을 사용합니다. USDT 기준 차이는 국내 USDT 시세를 사용하는 별도 지표입니다. 시세 지연·미래 시각·거래소 간 시각 차이가 크면 비교값은 — 입니다. 김프는 수수료·전송 시간·전송 가능성을 반영한 수익이 아닙니다.

연구실에서 Windows/Python 연구 엔진이 만든 결과 JSON을 열 수 있습니다(8MB 이하). 입력 파일을 변경하지 않습니다. 모바일은 별도 EMA 현물 CSV 백테스트와 관측 가격 실시간 모의매매를 포함합니다. 기존 Python/SQLite 엔진 자체는 모바일에 포함하지 않습니다. 기존 Windows GUI와 원본 Python 프로젝트는 별도 제공 파일로 보존되어 있습니다. 새 기능은 RELEASE_1_1_KO.md를 참고하세요. 실거래 코드는 operator/에 준비만 하며 사용자가 직접 가동합니다. v1.0/v1.1 설정의 모든 기능을 모바일에서 실행한다고 해석하지 마세요.
공개 시세 스냅샷 JSON은 사용자가 선택한 저장/공유 창으로 내보냅니다. 자동 업로드·계좌·실제 주문·API 키 기능은 없습니다.

온케어 채팅을 참고해 큰 숫자, 넓은 여백, 둥근 카드와 하단 탭을 사용합니다. iOS26 이상은 투명도 줄이기를 존중하는 Liquid Glass 제어부, Android는 네이티브 카드와 큰 제목입니다. 온케어의 건강 데이터나 서명 키는 포함하지 않습니다.

빌드/테스트 통과와 기기 설치 검증은 다릅니다. 실물 iPhone/Android 설치와 장시간 시세 연결은 별도 검증 대상입니다.
