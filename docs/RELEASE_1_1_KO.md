# 모바일1.1 변경과 실행 범위

연구실에 UTF8 CSV 백테스트 및 공개 시세 기반 실시간 모의매매를 추가했습니다. EMA9/21 현물 매수·청산, 다음 봉 시가/다음 관측 가격에 비용을 반영하며 입력 전략 설정과 원본 파일을 덮어쓰지 않습니다. 기존 Python v1.6 수치와 동일하다고 주장하지 않는 새 엔진입니다. v1.7 CVD/호가 신호와 유동성 증발은 미구현입니다.

CSV: timestamp,open,high,low,close,volume 헤더, UTC offset 시간, 순증가 순서, 올바른 OHLCV, 8MB/50000봉 이하. 시작 자본은 CSV 가격 통화와 같아야 합니다. 사용자 입력 자본·수수료·슬리피지로 실행합니다. 수수료/슬리피지는 각각0~100bps입니다. 백테스트는 마지막 가격에 비용을 적용해 모의 잔량을 청산합니다.

실시간: 선택 코인의 업비트 원화 관측 가격을1분봉으로 모읍니다. 첫 부분봉은 버리고30개 완성봉을 준비하므로 첫 시작 후30분 이상 필요합니다. 전체 거래소 체결의 완전한 OHLCV가 아닙니다. 기본 진입 자본10%, 손절1.5%, 익절3%, 시작 자본5%손실에서 신규 진입 중지를 적용합니다. 이는 모의 소프트웨어 기본값이며 투자 추천이 아닙니다. 수신15초 이상 공백·누락 봉·백그라운드·사용자 정지에서는 세션이 멈추며 모의 보유분을 유지합니다. 새 세션은 모의계좌를 초기화합니다.

모바일은 실제 주문/키/계좌 기능이 없습니다. 사용자 요청에 따른 자동매매 코드 준비본은 별도 operator/에 있으며 PC/서버에서 본인이 설정하고 가동합니다. 기본은 PAPER, 실거래 금액은 지정하지 않았고 실계좌 검증을 수행하지 않았습니다.

APK는 Android8+용 개발 서명, IPA는 iOS16+용 무서명 빌드로 재서명 설치가 필요합니다. 실물 기기 설치·장시간 시세·실계좌 체결은 별도 검증입니다. 기존1.0설치안내 중 ‘모바일에서 전략 실행 없음’ 설명은 이번1.1 문서로 대체합니다. Python/SQLite 원본은 여전히 PC용으로 보존합니다.
