# 전략 비교 (0.4.12)

투자와 리서치 > 전략 비교·비용 스트레스에서 CSV 또는 180봉 합성 예제를 실행합니다. 기존 CLASSIC/DEFENSIVE 엔진·기본 파라미터를 바꾸지 않습니다. 입력은 timestamp,open,high,low,close,volume UTF-8 CSV, 8MB/50000봉 상한입니다.

- 같은 자료의 기본·방어 결과: 비용 포함 수익률, 최대 낙폭, 청산 횟수, 손실한도 중지 상태.
- 수수료와 슬리피지를 각각2배로 재실행합니다. 어느 하나라도100bps를 넘으면 생략을 명시합니다.
- 앞70%/뒤30%를 각각 초기 현금·빈 지표·30봉 준비로 독립 실행합니다. 두 구간 모두30봉 이상일 때만 제공합니다. 최적화/자동 선택을 하지 않으므로 최적화 후 OOS 검증으로 표현하지 않습니다.
- 첫 시가 매수·마지막 종가 매도의 자본100% 보유 기준에도 양방향 수수료/슬리피지를 적용합니다. 전략은 기본10%·방어5% 배분으로 노출이 다르므로 단순 우열 판단에 사용하지 않습니다.
- 각 구간 최종 봉 청산을 포함합니다. 기존 엔진의 종가 신호 후 다음 시가 체결·손절 우선 규칙을 유지합니다. CSV 해상도보다 세밀한 유동성/호가/CVD를 추정하지 않습니다.
- 입력 변경 시 이전 결과를 지우고, 화면 이탈/취소 시 계산을 취소합니다. CSV·건강·음성·키를 업로드하거나 실주문을 실행하지 않습니다.
- JSON 비교 결과는 PAPER_STRATEGY_COMPARISON_V1 별도 포맷입니다. 기존 보고서/v1.0/v1.1 파일은 변환하지 않습니다.

검증: StrategyComparisonTests에서 기존 프로필 결과 동일성, 뒤 구간 독립 실행, 정확한2배 비용, 보유 기준 비용식, 입력 거절, 상한 생략을 확인합니다. UI 합성 실행과 기존 투자 탐색 회귀를 함께 실행합니다. 과거 모의 성과는 미래 수익·실제 체결을 보장하지 않습니다.
