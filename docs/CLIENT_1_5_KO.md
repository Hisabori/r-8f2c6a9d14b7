# 클라이언트 1.5 · Android One UI / iPhone OnCare

## 적용 범위

사용자 최종 요청에 따라 Android에만 One UI에서 영감을 받은 앱 자체 디자인을 적용했습니다. Samsung 시스템 One UI를 설치하거나 Samsung 전용 SDK를 포함하지 않습니다. Samsung 폰트·로고·아이콘을 복제하지 않고, 시스템 글꼴과 앱 자체 벡터 탐색 아이콘을 사용합니다.

iPhone은 기존 OnCare 디자인을 유지합니다. 기존 CareCard, CareControl, careBlue/careTeal 색상 정의와 네이티브 탭/탐색을 보존했습니다. iPhone에서 One UI 스타일로 교체하지 않았습니다.

## Android 변경

- 상단 큰 제목·요약은 스크롤되는 보는 영역에 배치하고, 하단에는 네 개 아이콘 탐색을 유지합니다. 넉넉한 여백, 28dp 카드, 52dp 이상 주요 버튼, 64dp 탐색 터치 영역을 사용합니다.
- 시스템/밝게/어둡게 테마를 설정에서 선택합니다. 마켓·관심·연구실·설정·백그라운드·서버 운영·성과 리포트에 같은 팔레트를 적용합니다.
- 글자는 sp 단위를 사용하고 입력/텍스트 영역은 내용에 맞게 높이를 늘립니다. 좁은 화면은 20dp 여백, 큰 화면은 최대 약760dp 콘텐츠 폭을 사용합니다. 실제 큰 글자/폴더블/회전 기기 점검은 별도입니다.
- 연구실 버튼을 전략 입력, CSV 백테스트, 실시간 모의계좌, 결과 저장 카드로 나눕니다.
- 종목 정렬(이름/김프 높은순)을 추가하고 검색 결과 없음과 관심 종목 없음을 구분합니다. 시세가 없는 종목은 김프 정렬의 뒤에 둡니다. 정렬은 선택/검색 갱신 시 재계산하며 매초 행 순서를 바꾸지 않습니다.
- 새 기기/로컬/서버 모의계좌가 기존 계좌를 초기화하는 경우 확인을 거칩니다. 취소하면 새 세션을 시작하지 않습니다.
- 테마 적용에 따른 화면 재생성 시 모의계좌/잔량/리포트/관측 자료를 보존합니다. 기존 수명주기 정책에 따라 로컬 모의계좌는 화면을 벗어나면 정지할 수 있고, 서비스가 소유한 세션은 유지합니다. 프로세스 강제 종료 후 자동 재개/완전한 화면 복원을 보장하는 기능은 아닙니다.

## iPhone 변경 (OnCare 유지)

- 기존 OnCare 색상·카드·유리 컨트롤·탭 구조를 그대로 유지합니다.
- 설정에 시스템/밝게/어둡게 선택을 추가합니다. 기본은 시스템입니다.
- 검색 결과 없음 안내를 구분합니다.
- 기존 로컬 모의계좌를 새로 만들거나 서버 새 계좌를 시작할 때 초기화 확인을 추가합니다.

## 기능·보안 호환

시세/김프 계산, 입력 자료 누락 처리, CSV/EMA 전략, 성과 계산, 기기 서비스 시간 제한, HTTPS 토큰/허용 경로, 서버 운영 조회는 유지합니다. iPhone의 상시 실행은 Ubuntu 서버가 담당합니다. 앱과 서버는 모의 전용이며 실제 주문을 호출하지 않습니다. operator 준비본·Ubuntu 서버1.4·원본 Windows/Python 프로젝트는 변경하지 않습니다.

서버 운영 센터는 서버1.4가 필요합니다. 서버1.3의 기존 상태/시작/정지/현재 리포트는 호환됩니다. 이번 패키지의 서버는 버전1.4이며 모바일 버전1.5와 다릅니다.

## 실행 및 검증

Android: JDK17/SDK35, android/에서 `gradle assembleDebug testDebugUnitTest lintDebug`.
iOS: Mac/Xcode26, ios/에서 `xcodegen generate` 후 기존 Actions의 device build와 simulator tests.

추가 검증: 밝은/어두운 팔레트 글자 대비, 탐색 터치 영역, 테마 재생성 후 계좌 보존, 새 계좌 확인/취소, 검색 빈 상태, iPhone OnCare 테마 화면. 기존 엔진·서버·운영 조회 회귀 검사는 유지합니다. APK/IPA 빌드와 테스트는 실제 기기 장시간 실행이나 Ubuntu 접속 검증과 구분합니다.
