# 코인·미국 주식 티커 종합 분석

온케어 → 투자와 리서치 → 코인·미국 주식 티커 분석에서 사용합니다. 이 화면은 주문 API·계좌·거래소 키를 읽거나 호출하지 않습니다. 가격 예측이나 매수/매도 권고가 아닌, 확정 일봉과 제목 표본의 규칙 기반 연구 요약입니다.

## 입력과 출처

- 코인: BTC, ETHUSDT 등. Binance 현물 USDT 페어, 공개 시장 데이터 전용 `https://data-api.binance.vision/api/v3/klines`, UTC 일봉 120개 요청. 진행 중 일봉 제외. 종목·지역·네트워크 제한은 실패 상태로 표시합니다.
- 미국 주식 우선: AAPL, MSFT, NVDA, 공급자가 지원하는 미국 티커. Alpha Vantage `TIME_SERIES_DAILY`, compact 일봉. 정규장 16:00 America/New_York 이전인 일봉은 제외합니다. 조기 폐장일은 16시까지 보수적으로 제외하며 거래소 캘린더를 완전히 구현한 것은 아닙니다.
- 주식 일봉은 분할·배당 **미조정**입니다. 기업행사로 인한 가격 단절을 추세 변화로 오인할 수 있습니다. 뉴스와 공시를 별도 확인해야 합니다. 미국 동부 시각 메타데이터가 아닌 응답은 거절하고, 미조정 주가가 하루 25% 이상 변하면 기업행사·원본 확인 전 종합 판정을 보류합니다. 국내 주식 자동 조회는 이번 범위에 포함하지 않습니다.
- 뉴스: Alpha Vantage `NEWS_SENTIMENT`, 해당 티커 관련성 0.2 이상인 항목의 제목·출처·링크·발행 시각만 사용합니다. 공급자 sentiment 수치를 상승 확률로 사용하지 않습니다.
- 코인 커뮤니티: 기존 지원 6종목 BTC/ETH/XRP/SOL/DOGE/ADA에 한해 디시 비트코인 갤러리 최신 목록 1페이지의 관련 제목 표본. 접근 제한·HTML 변경·표본 부족을 명시합니다. 전체 여론·봇 제거·작성자 검증을 주장하지 않습니다.
- 미국 주식 및 기타 코인 커뮤니티: 사용자 JSON 표본 추가. 자동 수집한 자료로 가장하지 않으며 출처 미검증 상태를 표시합니다. 제목·링크·시각만 가져오며 작성자·로그인·댓글·개인 정보는 수집하지 않습니다.

## 데이터 키와 요청

분석 화면의 ‘미국 주식·뉴스 데이터 연결’에서 **데이터 공급자 키**를 입력합니다. 키는 별도 서비스의 Keychain, ThisDeviceOnly에 저장됩니다. 거래소 주문 키·서버 토큰과 공유하지 않습니다. 공급자 요청 외에는 키를 전송하지 않으며 연구 JSON에 넣지 않습니다. 요청은 고정 HTTPS 호스트만 허용하고 리디렉션·쿠키·디스크 캐시를 사용하지 않습니다. HTTP 오류 본문과 키가 포함된 URL을 화면이나 로그로 출력하지 않습니다.

주식+뉴스는 수동 분석 1회당 최대 2회 공급자 API 요청입니다. 화면은 60초 간격으로만 조회하며 자동 폴링·재시도·백그라운드 조회는 하지 않습니다. 공급자 요금제·허용 종목·요청 한도를 확인하세요. API 키가 없거나 접근이 거절된 항목을 합성 자료로 채우지 않습니다. API 키를 채팅이나 소스 파일에 넣지 마세요.

- https://github.com/binance/binance-spot-api-docs/blob/master/faqs/market_data_only.md
- https://www.alphavantage.co/documentation/

## 계산과 종합 단서

- 최소 60개의 정렬된 확정 일봉. 잘못된 OHLC, 음수 거래량, 중복·역순·미래 시각, 비정상 수치는 거절합니다.
- SMA 20/50: 최근 종가 산술평균.
- RSI 14: 첫 14개 변화 평균으로 초기화한 Wilder 평활화. 변화가 없는 경우 50.
- MACD 12/26/9: 각 EMA는 최초 N개 평균으로 초기화. MACD 시그널은 유효 MACD 9개 평균으로 시작.
- 볼린저 20: 종가의 모집단 표준편차 ±2σ. ATR 14: 직전 종가를 포함하는 True Range의 Wilder 평활화.
- 상대 거래량: 최신 확정 일봉 거래량 / **최신 봉을 제외한** 직전 20개 봉 평균. 기준 평균 0이면 계산 불가. z-score는 기준 분산이 0이면 표시하지 않습니다.
- 특이점: 상대 거래량 2배, 시가 갭 3%, 수익률 z-score 절댓값 3, ATR/종가 5%, 볼린저 이탈, RSI 70/30. 특이점이 없다고 모든 위험이 확인된 것은 아닙니다.
- 제목 표본: 최근 7일, 미래 시각 제외, HTTPS 안전 링크, URL·제목 중복 제거. 상승/하락 표현 사전 집계이며 반어·부정·문맥·기사 본문을 이해한 분석이 아닙니다. 혼합 제목은 어느 방향에도 두 번 투표하지 않습니다. 커뮤니티는 티커 단어 또는 지원하는 회사명 별칭이 제목에 있는 표본만 포함합니다. 유효 표본 3개 미만이면 점수에서 제외합니다.
- 기술 60점 = SMA 추세 25 + MACD/시그널 20 + RSI 15. 최근 5일 변화 15, 상대 거래량으로 확인한 당일 방향 15, 뉴스 5, 커뮤니티 5. 누락된 항목의 가중치를 재분배하지 않습니다.
- 점수 ±25를 기준으로 ‘상방 단서 우세 / 하방 단서 우세 / 방향 혼재’. **입력 충족도는 정확도·상승 확률이 아닙니다.** 상관된 지표를 단순 합산한 설명 가능한 규칙이며 보정·수익 검증을 주장하지 않습니다.
- 코인 최근 봉 2일, 주식 7일 초과·60봉 미만·합성 예제는 종합 판정을 보류합니다. 주식 7일 기준은 보수적인 데이터 중단 탐지이며 휴장 캘린더가 아닙니다.

## 연구 JSON v1

2MB 이하. `research_schema_version:1`, `asset:"crypto"|"stock"`, 정규화된 `symbol`(BTCUSDT/AAPL), `synthetic:Bool`, `bars`, `news`, `community` 필수. 날짜는 ISO8601. bars의 각 항목은 `time`(봉 마감 시각), `open`, `high`, `low`, `close`, `volume`, `closed:true`. 제목 항목은 `source`, `title`, `url`, `time`. 현재 화면의 자산·티커와 일치해야 합니다. 스냅샷 저장으로 동일 스키마를 내보낼 수 있으며 키·계좌·개인 기록은 포함하지 않습니다. 가져온 자료의 출처는 검증되지 않았다고 표시합니다.

커뮤니티만 추가할 때는 이미 분석한 티커에 대해 다음 v2 파일을 사용합니다. `posts`는 동일한 제목 항목 형식이며, 스키마의 티커 표기는 파일 작성자의 주장입니다. 합성 표본을 추가하면 전체 종합 판정을 보류합니다.

```json
{
  "community_schema_version": 2,
  "asset": "stock",
  "symbol": "AAPL",
  "synthetic": false,
  "posts": []
}
```

## 검증 기준과 한계

독립적인 RSI 기준값, 선형 EMA/MACD, 거래량 분모, 평탄한 시계열, 미래·중복·정렬 오류, 현재 형성 봉 제외, 미국 장 마감, 뉴스 종목 관련성, 표본 중복·기간·링크, 부분 공급자 실패를 고정 fixture로 검사합니다. UI 검사는 합성 버튼으로 네트워크·키·주문 없이 실행합니다. 공급자의 실응답은 지역·종목·키·요금제에 따라 달라집니다. 사용자 키를 이용한 주식·뉴스 실조회, 실제 기기 동작, 성과·예측 정확도는 별도 검증입니다.
