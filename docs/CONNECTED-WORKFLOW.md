# 연결된 투자 작업 (0.4.13)

1. 투자와 리서치 > 티커 분석에서 가격 자료를 조회하거나 합성 예제를 엽니다.
2. `이 일봉으로 전략 비교`를 누르면 해당 스냅샷의 OHLCV·종목·통화·합성 여부·분석 시각을 복사합니다. 뉴스/커뮤니티 점수로 주문·전략 파라미터를 자동 변경하지 않습니다.
3. 비교 화면에서 자본·비용을 확인하고 `전달받은 일봉 비교`를 눌러 실행합니다. 화면 전환만으로 계산을 시작하지 않습니다.
4. 비교 입력과 결과는 앱 세션의 공유 작업 공간에 남습니다. 다른 화면을 보고 홈의 투자 > 전략 비교에서 이어볼 수 있습니다. 앱 강제 종료 후 결과 복원을 보장하지 않습니다.
5. 지원 코인만 같은 기초자산의 KRW 관측 시세로 연결합니다. USDT 분석 가격과 KRW 시세 기준은 다릅니다. 미국 주식과 미지원 코인을 BTC로 대체하지 않습니다.

입력 종목을 나중에 변경해도 이전 비교 스냅샷을 소급 변경하지 않습니다. 전달받은 자료와 이번 결과 입력 출처를 별도 표시하며, CSV나 예제 실행 결과에 이전 티커를 붙이지 않습니다. 기존 비교 JSON은 optional inputLabel 없이도 읽을 수 있습니다.

ResearchBar.time은 확정 일봉 종료시각이며 전략 봉 식별자로 보존합니다. 실제 장중 체결 시각을 재현하지 않습니다. 주식 기업행사·미수정 일봉 한계와 원래 분석 출처를 별도 확인해야 합니다. 합성 자료는 끝까지 합성으로 표시합니다.

건강·음성·이동 자료는 투자/전략 모듈에 전달하지 않습니다. 거래소 키·서버 토큰이나 주문 수량/가격을 자동 복사하지 않습니다. 실주문은 기존 검토·사용자 확인 절차를 유지합니다.

검증: InvestmentWorkflowTests의 OHLCV 매핑·스냅샷 불변성·통화/합성 보존·주식/미지원 코인 거절·구형 JSON 호환·실제 전달 봉 실행, UI 티커→비교→뒤로→비교 재진입을 실행합니다. 실제 기기·실주문은 별도 검증입니다.
