# 서버 연결 개선 (iOS 0.4.14)

투자와 리서치 > 거래소와 연결 설정 > 거래소 API 설정 가이드에서 서버 기본 HTTPS 주소와 서버 토큰을 입력합니다.

- 서버 응답 확인: /health만 요청하며 토큰을 보내지 않습니다. 이 성공은 토큰·계좌 연결 성공을 뜻하지 않습니다.
- 설정 저장: 기존 Keychain service를 유지합니다. 변수명과 = / Bearer 접두사를 붙인 값, 내부 공백·비ASCII·길이 오류를 저장 전에 안내합니다.
- 연결 및 권한 확인: 읽기/제어 토큰 역할, 서버 실주문 켜짐/꺼짐, 마지막 확인 시각을 표시합니다. 조회 토큰으로 연결돼도 실주문 가능하다고 표시하지 않습니다.
- 실제 주문 검토/제출/취소는 현재 주소·토큰에서 확인한 제어 권한과 서버 활성 상태를 요구합니다. 매 주문별 수동 확인·30초 검토 만료·결과 불명 시 상태 조회 규칙을 보존합니다. 서버도 권한을 다시 검증합니다.
- 401/403/404/409/429를 구분하고, 제출·취소의 불명확 결과 안내를 조회 오류와 분리합니다. 원문 응답·토큰·키 포함 URL을 로그에 넣지 않습니다. 자동 재시도는 없습니다.
- 통신은 HTTPS/리다이렉트 차단/임시 세션/20초 자원 제한/1MB 스트림 상한을 적용합니다. 초기화나 화면 진입 시 자동 연결하지 않습니다.

검증은 URLProtocol 가짜 전송과 합성 값으로만 수행합니다. 실제 토큰·거래소 계좌·주문을 사용하지 않으며 실제 기기 네트워크·서명·설치는 별도 검증입니다.
