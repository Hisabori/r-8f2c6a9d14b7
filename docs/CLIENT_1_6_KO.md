# 모바일 1.6 기능 개선

Android One UI 스타일과 iPhone OnCare 디자인을 유지했습니다. 모바일1.6은 원본 Python v1.6과 별개 버전입니다. 서버는 기존1.4를 사용합니다.

## 새 기능

1. **연구실 입력 초안 보존**: 자본·수수료·슬리피지가 화면 이동과 앱 재실행 뒤에도 기기에 남습니다. 연구실(입력 가격 통화)과 기기/서버 실행(KRW)은 별도 저장합니다. 입력은 최대32글자이며 빈 값도 초안으로 보존합니다. 실행 때 기존 숫자/범위 검사를 적용합니다. 입력/기본값 복원은 실행 중인 모의계좌를 변경하지 않습니다.
2. **현재 모의계좌 요약**: 연구실 실시간 계좌에 관측 평가액·현금·보유 수량과 실행/정지·신규 진입 중지 상태를 표시합니다. 기존 엔진의 잔고와 마지막 관측 가격을 읽으며 별도 체결이나 가격을 만들지 않습니다. 오래된 관측 평가액은 현재 거래 가능 가격을 뜻하지 않습니다.
3. **서버 리포트 저장**: 현재 서버 리포트와 이전 세션 리포트를 JSON으로 저장/공유합니다. 서버 모의 모드·schema2·8MB 제한을 검사하고 받은 JSON 바이트를 그대로 보존합니다. 앱의 서버 URL·로컬 토큰·HTTP 헤더를 덧붙이지 않습니다. 저장/공유 대상은 사용자가 시스템 화면에서 선택합니다.
4. **이전 세션 종목 필터**: 전체/BTC/ETH/XRP/SOL/DOGE/ADA로 조회한 최근100개 목록을 좁힙니다. 서버 전체 데이터에서 추가로 검색하는 기능은 아닙니다. 리포트의 종목/시각과 현재 계좌를 구분합니다.

Android 공유는 읽기 권한이 있는 앱 전용 JSON URI를 사용합니다. iPhone은 기존 FileDocument 저장 화면을 사용합니다. 공유/저장 실패는 화면에 표시하며 서버 세션을 바꾸지 않습니다. 입력 초안은 토큰 보안 저장소와 분리되어 일반 앱 설정에 저장되므로 API 키를 입력하는 필드가 아닙니다.

## 유지되는 범위

EMA/CSV 전략·김프 계산·시세 지연 처리·서버 API·백그라운드 서비스 시간 제한은 변경하지 않습니다. 앱과 서버는 모의 전용입니다. 원본 Windows/Python 프로젝트, operator 준비본, Ubuntu 서버1.4는 변경하지 않습니다. 실제 주문·서버 배포는 수행하지 않습니다.

## 실행/검증

- Android: JDK17/SDK35, android/에서 `gradle assembleDebug testDebugUnitTest lintDebug`.
- iPhone: Mac/Xcode26, ios/에서 `xcodegen generate`; 기존 GitHub Actions device build + simulator tests.
- 새 검사: 화면 전환/재생성 후 입력 초안, 범위 제한·초안 분리·계좌 불변, 원본 서버 JSON 보존/잘못된 모드 차단, 계좌 요약 계산, 오프라인 세션 필터 화면.

기기 강제 종료 후 실행 중인 계좌 자체를 자동 복원·재개하는 기능은 이번 입력 초안 저장과 다릅니다. 서버/Android 서비스의 기존 복구·정지 정책을 유지합니다. 실제 기기 장시간 실행과 Gram의 외부 HTTPS 연결은 별도 검증이 필요합니다.
