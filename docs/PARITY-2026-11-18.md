## 데이터 해석
- 열차 위치는 서울시 arvlCd와 생성시각에 따른 개요입니다. GPS 지도 좌표·연속 위치 추정이 아닙니다. 오래된 자료에서는 위치를 표시하지 않습니다.
- 객실 그림은 원본 Flutter의 원근 도형과 밀도 규칙을 네이티브로 옮긴 것입니다. 사람 아이콘은 실제 승객 수가 아니며 객차별 실시간 혼잡도·좌석 보장이 아닙니다.
- 평균 통계는 2026-06-30 서울교통공사 30분 자료입니다. 제공 값이 없으면 0%로 채우지 않습니다. 공휴일 유형은 사용자가 선택합니다.
- 실제 청산은 Bybit 15초 관측이며 Coinglass 미래 추정맵과 다릅니다. 키 없는 관측과 서버의 유료 Coinglass 기능은 대체 관계가 아닙니다.
- 이전 반려 메타데이터를 이관해도 타 앱 샌드박스의 원음은 자동 접근하지 않습니다. 원음은 사용자가 파일 선택으로 가져와 재분석합니다.

## 동등 구현으로 표현하지 않는 항목
- iPhone HealthKit·다이내믹 아일랜드·Apple Intelligence는 해당 OS/지원 기기 전용입니다.
- 카카오 고유 POI/자동차 대안 경로·도로 형상과 지도 내 탐색은 현재 각 OS 지도 연결과 동일 구현이 아닙니다. 카카오 API 권한과 별도 구성에 의존합니다.
- 기존 Flutter의 실시간 짖음 스트림은 현재 파일/녹음 후 YAMNet 분석과 동일하지 않습니다. 이 기능을 실시간으로 구현했다고 표시하지 않습니다.
- 실제 서울시 HTTPS 요청은 이번 환경에서 시간 초과되어 인증 성공/운행 자료 수신은 미검증입니다. 키 기본 설정과 실제 인증을 구분합니다.
