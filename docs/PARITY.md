# 기능 이식과 검증 기준

## 보존하거나 네이티브로 구현한 범위

| 기능 | 구현 | 검증 기준 |
|---|---|---|
| 온케어 전체 | 기존 SwiftUI 소스·알림·HealthKit·저장·ONNX 유지 | 기존 회귀 테스트, 권한 거절·딥링크 실기기 검증 |
| 투자와 리서치 | 기존 Swift 모듈, SwiftUI 탐색으로 직접 연결 | 열기·뒤로가기, 가짜 주문 전송 테스트; 실주문 자동 검사 금지 |
| 반려견 파일 분석 | AVAudioFile/Converter + 동일 YAMNet/가중치/임계값 | 합성 오디오 실제 추론, 입력/출력 모양, 기존 녹음과 결과 비교 |
| 반려견 녹음 | AVAudioRecorder, 사용자 시작, 60초 상한 | 권한 거절·전화·배경·이탈 시 종료 실기기 확인 |
| 후보 패턴·기록 | 겹치는 모델 창 병합, 구간·묶음·지속시간, 원자 저장 | 중복 창/비정상 값/묶음 간격 테스트, 손상 파일 보존 |
| 이동 준비 | MapKit 목적지 검색, 현재 위치 선택 요청, 도보 ETA와 준비/여유 시간 | 빈 결과·위치 거절·오래된 검색 결과 무시·시간 계산 |
| 대중교통 길찾기 | 선택 목적지를 Apple 지도 대중교통으로 전달 | 사용자가 지도 앱에서 실제 경로 확인 |

## 아직 동등 이식을 완료하지 않은 범위

1. Flutter 반려견 JSON/프로필/녹음 이관: 기존 파일을 보존하고 미리보기·스키마 검증·사용자 선택·중복 방지 후 가져오기 구현. 기존 폴더 자동 삭제 금지.
2. 실시간 짖음 후보: 현재는 녹음 종료/파일 가져오기 후 분석. AVAudioEngine 스트림과 bounded ring buffer, 순서·드롭·오디오 경합 테스트 후 제공. 입력 음량을 모델 실시간 추론으로 표시하지 말 것.
3. 기존 품종 비교·일별 통계·녹음 내보내기 UI: 데이터 스키마와 검증된 설명을 먼저 이식. 감정 번역/정확도 보장 금지.
4. 서울 지하철 실시간 도착·혼잡도·Kakao POI/노선 탐색: 출처·수신 시각·120초 freshness·방향·환승 계산을 Swift로 이식하고 fixture 회귀 테스트 추가. 현재 MapKit 도보 ETA를 지하철 ETA로 표시하지 말 것.
5. 반려 녹음/파일 분석·도보 준비·리서치 상태 Live Activity는 0.4.0에서 시작/갱신/종료와 딥링크를 연결했습니다. 지하철 실시간 및 라이브 짖음 스트림 표시의 동등 이식, 실제 다이내믹 아일랜드 기기 검증은 남아 있습니다. 온케어 건강 Live Activity는 기존 흐름을 유지하며 좁은 숫자·갱신 지연 표시를 보완했습니다.
6. 전체 앱의 큰 글씨·VoiceOver·iPad·다크/마음 테마·오디오 전환 실기기 검증. 소스 검사나 시뮬레이터 성공으로 대체하지 말 것.

이 버전은 Flutter를 제거한 첫 네이티브 재설계본입니다. 기존 Flutter 통합본의 모든 기능과 데이터 이관이 동등하다고 설명하지 않습니다. 기존 IPA와 소스 ZIP은 그대로 보존합니다.
