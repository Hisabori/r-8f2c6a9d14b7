# 공통 흐름과 다이내믹 아일랜드 0.4.0

## 세 앱을 하나의 흐름으로

온케어의 기존 하단 메뉴와 상태 소유자를 유지합니다. 오늘 화면의 일상 카드에는 최근 반려 기록, 선택한 이동 목적지, 마지막 티커 분석 스냅샷을 표시하고 티커 분석 바로가기를 제공합니다. 별도 앱 이름·런처·복귀 막대를 추가하지 않습니다.

앱 수명주기에서 반려 기록/입력, 이동 검색/선택/준비 시간, 투자 시세/관심/리서치 입력과 결과를 소유합니다. 화면을 뒤로 갔다 다시 열어도 세션 상태를 유지합니다. 앱 종료 후 모든 미저장 입력 복원을 보장하지 않으며 기존 저장·가져오기 규칙을 바꾸지 않습니다. 세션 생성은 마이크·GPS·시세 요청을 시작하지 않습니다. 현재 위치는 직접 요청한 경우에만 획득하고 화면 이탈 시 요청과 경로 계산을 취소합니다.

## 사용자가 요청한 건강·투자 결합

‘내 건강 기록 함께 보기’는 기본 꺼짐입니다. 켜면 기기에 있는 48시간 이내 수면 기록과 오늘 마음 기록을 최근 투자 리서치와 함께 보여줍니다. 기록이 없거나 미래인 경우 값을 만들지 않습니다. 사용자가 ‘컨디션과 분석 함께 기록’을 누르면 선택한 요약·메모·리서치 식별자/판정/시각을 보호된 로컬 파일에 원자 저장합니다. 합성 연구 자료는 함께 저장하지 않습니다.

기존 건강 기록은 변경하지 않습니다. 데이터는 주문 API·가격 지표·방향 점수·공급자 요청·리서치 JSON·Live Activity로 흘러가지 않습니다. 공유하는 것은 앱 화면과 선택형 개인 메모이며, 건강으로 수익률을 예측하거나 주문을 자동 변경하는 기능이 아닙니다. 연결 표시를 꺼도 이미 작성한 개인 일기는 기기에 남습니다. 손상된 파일은 덮어쓰지 않으며 500개 보관 상한에서 새 저장을 거절합니다.

## 아일랜드와 잠금 화면

- 반려생활: 선택한 경우에만 녹음/파일 분석 진행 표시. 녹음은 최대 60초, 로컬 갱신은 약 5초 간격, 15초 미갱신 시 확인 상태. 파일 분석은 90초 기준 만료, 완료 결과는 잠시 표시 후 종료합니다. 녹음을 실시간 모델 추론으로 표시하지 않습니다. 이름·원음·메모는 표시하지 않습니다.
- 이동: 도보 ETA와 준비/여유 시간을 계산한 뒤 ‘준비 시각을 잠금 화면에 표시’를 눌러 시작합니다. 정확한 목적지 이름/주소를 넣지 않고 준비 시각과 도착 목표를 표시합니다. 2분 뒤 경로 갱신이 필요하며 지하철 실시간 예측으로 가장하지 않습니다. 선택·목표·여유 시간이 바뀌면 이전 표시를 종료합니다.
- 리서치: 별도 선택형 ‘자료 확인 진행’만 표시합니다. 가격·티커·계좌·건강·방향 점수를 표시하지 않습니다. 앱 안에서 화면을 이동하는 동안 같은 수동 조회를 이어가고, 요청이 끝나거나 직접 중단하면 표시를 종료합니다. 앱이 배경으로 가면 조회를 취소하고 표시를 종료합니다. 외부 서버 푸시·백그라운드 전략 실행을 추가하지 않습니다.
- 온케어: 기존 걸음·수면·운동·건강 연결 표시를 유지합니다. 큰 걸음 수는 작은 영역에서 축약하고, 오래된 운동 상태는 계속 진행 중인 것처럼 표시하지 않도록 보완했습니다.
- 고정 서비스 URL `caresuite-care://service/pet|travel|investment|ticker`로 해당 화면을 엽니다. 토큰·건강·종목 데이터를 URL에 넣지 않습니다. 기존 건강 URL/바로가기는 유지하며 최신 유효 요청을 우선합니다. 서비스 딥링크는 현재 모달을 닫을 수 있으므로 원본 온케어 폼의 기존 미저장 처리 규칙을 따릅니다.

실시간 현황 권한·서명·기기 지원·시스템 정책에 따라 표시 여부와 배치가 달라집니다. 앱은 iOS의 아일랜드 우선순위를 강제하지 않습니다. 시뮬레이터/컴파일/정책 테스트는 실물 기기의 아일랜드 크기·배터리·백그라운드 유지·잠금 상태·알림 동작을 증명하지 않습니다.
