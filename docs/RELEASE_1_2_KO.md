# 모바일1.2 기능 고도화

- CSV 연구 결과에 손익 곡선, 승률, 순손익비, 누적 수수료와 최근100개 구조화 체결 내역(시각·가격·수량·비용)을 표시합니다. 빈 값/정의 불가 비율은 — 로 남깁니다.
- 기존 모의매매 계산식과 기본 비용/리스크를 변경하지 않았습니다. 마지막 모의 청산 뒤의 잔고를 마지막 곡선 점에 반영합니다. 봉 내부 실제 경로/체결과 동일하다고 주장하지 않습니다.
- 지표는 전체 청산 거래에서 계산합니다. 화면 곡선은 극값을 보존한 표시용 샘플링이며 원본 CSV report JSON은 최대50000봉을 보존합니다. 실시간은 최근3600봉, 체결은5000개로 제한하며 절단 여부를 기록합니다.
- report_schema_version2의 equity_curve/fill_records/통계 필드를 추가했습니다. 기존 mode/fills/요약 필드는 보존합니다. 시각은 입력/관측 봉 timestamp 기준, 통화는 CSV 입력 가격 통화 또는 실시간 KRW입니다. 임의 환산하지 않습니다.
- 실시간 모의세션에30봉 워밍업 진행률을 표시합니다. 중단·공백·잔여 보유 정책은1.1과 같습니다.
- 자동매매 operator 코드는1.1과 동일합니다. 사용자가 직접 설정·가동하는 준비본이며 이 작업에서 인증 API·실제 주문·배포를 실행하지 않습니다. 실계좌 연동과 실물 기기 설치는 별도 검증입니다.

테스트용 합성32봉의 기본 자본1000000/비용각5bps에서 최종999800.1998501을 회귀 확인합니다. 이는 실제 시세나 투자 성과가 아닙니다.

합성 테스트32봉 바로 실행 버튼으로 파일 전송 없이 결과 화면을 확인할 수 있습니다. 합성 자료임을 화면에 표시하며 실제 시세나 성과로 제시하지 않습니다.
