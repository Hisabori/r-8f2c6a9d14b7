# 클라이언트 1.4 변경 사항

Android / iPhone 연구실 → 백그라운드·Ubuntu 서버 → 서버 운영 센터를 추가했습니다.

- 진단: 서버 버전·모의세션 상태·프로세스 가동 시간·시세 수신 횟수·재연결 횟수·작업 상태·DB 본체 크기.
- 운영 기록: 최근 50개씩 조회하고 이전 기록으로 이동합니다. 시작·정지·복원·시세 재연결·서버 작업 중단을 구분합니다.
- 이전 세션: 서버의 최근 100개 보관 계좌와 개별 리포트·곡선·모의 체결을 조회합니다. 새 모의세션 시작 시 직전 계좌가 보관됩니다. 현재 계좌와 구분합니다.
- 수신 시각, 조회 중/오류 안내. 네트워크 오류일 때 기존 표시를 최신으로 취급하지 않습니다.
- 화면을 벗어나면 운영 조회 결과의 반영을 중단합니다. 운영 조회는 사용자가 새로고침할 때만 수행합니다.
- 서버 주소·토큰 편집 후에는 저장된 설정과 일치할 때만 시작/정지할 수 있습니다. 이전 설정으로 요청한 상태 응답이 새 설정의 권한으로 반영되지 않도록 했습니다.

운영 조회는 서버 1.4 이상이 필요합니다. 기존 서버 1.3에서도 상태·시작·정지·현재 리포트는 유지되며, 새 운영 경로가 없으면 업데이트/기록 없음 안내를 표시합니다. 서버 운영 센터에는 실제 주문·서버 재시작·백업 삭제 버튼을 넣지 않았습니다. 서버1.4 운영 도구는 background_server/OPERATIONS_KO.md를 참고하세요.

HTTPS·토큰 저장(Keychain/Keystore)·리다이렉트 거부·응답 8MB 제한을 유지합니다. 운영 경로/세션ID/커서 허용 목록을 사용하며, 토큰은 URL이나 Android Intent에 넣지 않습니다. 서버 응답 문구는 텍스트로 표시합니다.

기존 EMA 모의 엔진·시세/김프·CSV 백테스트·Android 제한된 포그라운드 서비스는 유지합니다. iPhone의 지속 실행은 Ubuntu 서버에서 수행합니다. Android 기기 백그라운드 실행은 최대5시간45분이며 OS 중단이 적용됩니다. 모바일·서버는 모의 전용입니다. operator/ 준비본은 독립적이며 이번 변경에서 실행하지 않습니다.

## 실행·검증

Android: Java17/Android SDK35, android/에서 `gradle assembleDebug testDebugUnitTest lintDebug`.
iOS: Mac/Xcode26, ios/에서 `xcodegen generate`, 기존 GitHub Actions의 device build + simulator tests.
서버: `pip install -r background_server/requirements-dev.txt` 후 `pytest background_server/tests`.

테스트는 HTTPS 주소·요청 경로/커서 경계, 모의 응답 검증, 운영 데이터 파싱, 화면 종료, 기존 전략/화면 회귀를 포함합니다. CI·모의 응답 검사는 실제 Ubuntu 연결·휴대폰 장시간 실행 검증과 다릅니다. 무서명 IPA는 본인 계정 재서명이 필요합니다.
